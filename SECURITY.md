# Security policy

Please report vulnerabilities privately through GitHub Security Advisories for
`maelys-dev/maelys-http`. Do not open a public issue before maintainers have had
an opportunity to assess and coordinate a fix.

Security reports should include affected version/commit, a minimal byte stream
or reproducer, expected and observed framing verdicts, build platform and
sanitizer output when available.

Only the latest released minor line receives security fixes during 0.x.
